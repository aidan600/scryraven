# Experimental research-capability baseline

## Objective

Build evidence-grounded research that can show why its answer follows from what
it actually read, while preserving useful partial or unable answers when the
available material does not establish a broader claim.

## Current semantic flow

```text
question + retained actual Evidence
        -> Research: compact understanding and acquisition/stopping choice
        -> mechanical Search / Read / Find
        -> immutable Evidence custody
        -> fresh source-first Answer
        -> exact readings, citations, neutral completed session result
```

Research and Answer are the only semantic decision-makers. Research's compact
continuity is not Evidence; Answer receives actual selected source material, not
Research's generated verdict. The default experimental target is GPT-5.6 Luna /
medium. The production Research -> Analyst -> Author path is unchanged.

## Surviving foundations

Evidence has canonical source identity, immutable versions/views, exact local
rereading and retained follow-up reuse. Search/Read/Find are mechanical. Answers
use exact citations and selected readings, including multiple literal contiguous
passages from one source. Neutral results, sessions, history, no-progress
handling, terminal Answer reservation, safe timeouts and pending-material guards
remain part of the candidate.

## Boundaries

The candidate is experimental, unpublished, and not a production replacement.
Custody and literal-reading mechanics are demonstrated; general semantic
reliability is not. Aggregate/open-world sufficiency is unresolved: incomplete,
heterogeneous evidence must yield the strongest warranted bounded synthesis, not
an invented aggregate conclusion.

The failed Observation/Inference/scope contract, stopped Investigator lineage and
other no-signal work remain historical development evidence only. No compatibility
adapter, new verifier, model router, schema intervention or additional product
path is carried forward from them.

## Next development posture

Use Luna / medium first. Use Terra / medium only as a bounded capability
counterfactual when a Luna result cannot distinguish model limitation from harness
quality. Sol is a rare authorized diagnostic, not the ordinary reference model.
Progress diagnostically through authoritative lookup, qualified interpretation,
comparison, bounded synthesis, one-hop discovery, recursive identity/chronology,
open-world aggregate synthesis and dynamic multi-component research. This is one
capability ladder, not eight architectures or a mandate to begin any rung now.
