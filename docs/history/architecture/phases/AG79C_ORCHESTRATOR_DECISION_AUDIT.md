## Executive verdict

The orchestrator now has several Controller-owned handoffs that are real runtime gates: retrieval stop/continue, weak-corpus recovery admission, source-class recovery dispatch, conflict-resolution retrieval, targeted/ordinary continuation spine authorization, citation/source-list identity handoff, and Analyst/Author handoff packaging. Those are classified as `Controller-owned handoff` where the audited branch consumes their decision output.

The largest remaining hidden authority is **Scrutineer/remediation**. It has an orchestrator-local run gate, flag threshold, searchable-category filter, LLM-generated remediation queries, novelty filter, local provider/depth selection, re-synthesis trigger, and Author directive insertion. Those branches can search, re-synthesize, caveat, hedge, omit, or alter Author context without a dedicated Controller-owned remediation handoff. Because this is deeper and more final-answer-governing than supplemental search, AG-76D-SCR should be elevated next.

The second-largest remaining hidden authority is synthesis-evaluator supplemental search. It can trigger supplemental retrieval, choose supplemental providers/depth, insert Author notes, rebuild final evidence, and re-run the Analyst. It should eventually receive a dedicated Controller-owned handoff, but AG-79C does not recommend it before Scrutineer/remediation.

Provider/search/depth/query authority that AG-79B classified remains behavior-preserving and static; no runtime wiring occurred. Final evidence/citation/Author assembly has Controller-owned identity handoffs, but prompt text, prompt semantics, citation formatting, source ordering, and Author prose remain protected legacy behavior.

## Remaining active hidden-authority clusters

1. **Scrutineer/remediation**: run gate, flag threshold, searchable category filter, remediation query generation, novelty filtering, provider/depth selection, re-synthesis trigger, and Author directive insertion are orchestrator-local and final-answer-governing.
2. **Synthesis-evaluator supplemental search**: completeness check, supplemental trigger, supplemental queries, provider/depth selection, evidence rebuild, Analyst re-run, and Author note are active but not governed by a dedicated handoff.
3. **Recon/disambiguation retry and residual query-source branches**: local query replacement or retry can change retrieval without a dedicated Controller-owned handoff.
4. **Scout/expander/evaluator continuation fixtures**: these branches have Controller gates, but need fixture proof that query/provider scheduling cannot bypass the gates.
5. **Author-note side channels**: nutrition/quantitative, supplemental, Scrutineer, recency, weak/failure, and image-context notes are mixed in the final prompt; some are Controller-owned, some are protected legacy, and some are hidden authority.

## Scrutineer/remediation decision

AG-76D-SCR should be **elevated next**. Scrutineer/remediation is the highest-risk active hidden-authority cluster because it can initiate additional search, select providers/depth, re-run analysis, and insert explicit Author directives to hedge, omit, or caveat claims. It is more final-answer-governing than adapter cleanup and more concentrated than the supplemental-search cluster.

AG-76D-SCR should be docs/static and fixture-first unless separately licensed for behavior changes. Its initial goal should be to define a Controller-owned Scrutineer/remediation handoff contract and static tests for run eligibility, flag classification, remediation-query admission, provider/depth posture, re-synthesis admission, and Author directive identity. It should not change Scrutineer prompt text, provider behavior, retrieval behavior, or Author prose unless a later repair phase explicitly licenses runtime wiring.

## Synthesis-evaluator supplemental-search decision

Synthesis-evaluator supplemental search should eventually get its own Controller-owned handoff. However, AG-79C does **not** elevate it as the next phase because Scrutineer/remediation has a broader final-answer effect and more local decision points.

Supplemental search remains `active hidden authority` until a future handoff captures completeness decision, supplemental trigger, query identity, provider/depth posture, re-analysis admission, final evidence rebuild identity, and Author-note identity.

## AG-76D-AD adapter cleanup decision

AG-76D-AD remains **parked**. Adapter and trace/projection debt does not currently block safe static review or the recommended Scrutineer/remediation handoff planning. Adapter cleanup should become necessary only if a later repair cannot distinguish adapter translation from Controller-owned action authority or if projection/export code is shown to mutate runtime decisions.

## AG-78G decision

AG-78G remains **live-gated**. AG-79C did not run live dogfood, live product-path commands, provider/model calls, search calls, or local-output validation. No live validation is licensed here, and AG-78G should not proceed unless explicitly authorized.
