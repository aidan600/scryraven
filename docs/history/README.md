# Historical reference library

This library contains dated technical retrospectives for learning and reference.
It records historical experiments, decisions, successes, failures and uncertainty.
It is optional reading, not coding-agent startup context or a roadmap.

## October 1, 2026 edition

[ScryRaven Research 101 and Counting](research-101-and-counting.md) covers selected
history from the May 27 public snapshot through merged PR #665 at
`8f4cb39f1f8e27b2d9ee43f9e1b4c36b15c68fb6`.

- Start with the [executive overview](research-101-and-counting.md#executive-summary)
  for the demonstrated product and its engineering journey.
- Use the [experiment index](research-101-and-counting.md#experiment-library)
  to find a tested mechanism and its bounded disposition.
- Consult the [annotated source register](research-101-and-counting.md#source-register)
  for pinned public records, local-only report locators and access limitations.

Current product intent, factual state and architecture live in
[PRODUCT.md](../../PRODUCT.md), [CURRENT.md](../../CURRENT.md) and the
[current research architecture](../architecture/RESEARCH.md). Historical prompts,
configurations and rejected mechanisms are not active instructions, standing
restrictions or future execution authority. An old decision to park an experiment
does not prohibit a later approved investigation.

The edition's historical outcomes stay frozen. Label factual corrections with
their source and edition; later work belongs in another dated edition or entry.
